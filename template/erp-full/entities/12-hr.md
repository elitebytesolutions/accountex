# 12 · HR — page → entity map (Full edition)

22 screens. Schema: `database/schema/11-hr.sql` (49 tables plus a default punch partition), cross-module FKs: `database/fk/11-HumanResources-fks.sql`.
Payroll screens (`app/humanresources/Payroll*`, loans, settlement) are in `13-payroll.md`. ESS screens are in `14-ess.md`, which reuses `HumanResources.RegularisationRequests`, `HumanResources.LeaveRequests`, `HumanResources.Goals`/`HumanResources.KeyResults`, `HumanResources.OneOnOneMeetings`, `HumanResources.PerformanceFeedback` and `HumanResources.OnboardingTasks`.

Conventions used below:
- **Derived** means the value is computed by a view or query and is not stored.
- `Company.ActivityEvents` / `Company.AuditTrailEntries` feed every timeline.
- Approvals that go through the core engine carry `approvalRequestId` (`Company.Approvals`).
